# What a hub installs. PINNED, not `>=`.
#
# This file asked for `>=` on everything until CI proved why that is not
# good enough: a clean machine resolved anyio 4.16 against 4.14, starlette
# 1.10 against 1.3 and fastapi 0.162 against 0.139, and the suite hung
# until the job timed out. The same `pip install` on the VPS would have
# done the same thing, silently, to a system that moves real money -- the
# difference being that nothing there would have told anyone.
#
# So an upgrade is now a deliberate act: change a version here, regenerate
# constraints.txt, run the suite, commit the result together. The pins here
# must agree with constraints.txt, and tests/test_requirements.py fails if
# they ever stop agreeing.
